# Odin Chess
A basic command-line chess program written in Ruby for The Odin Project.
Supports player vs player and a very basic CPU that chooses its moves randomly.

## Installation
- You will need to install [ruby](https://www.ruby-lang.org/en/documentation/installation/) and [rubygems](https://rubygems.org/pages/download).
- In the terminal, navigate to the program's folder. (e.g. ~/Downloads/odin-chess)
- Enter the following into your terminal:
`bundle install`
- Everything should be installed and ready!

## How to Use
Run the program by navigating to the folder in your terminal and running:
`ruby main.rb`

Any time you are prompted for a move, you can instead enter 'save' to save your game.

The program accepts [standard algebraic notation](https://www.chess.com/terms/chess-notation). It will understand unecessary specificities if you provide them (eg: 'e2e4' instead of 'e4'). It is not required to specify takes.
